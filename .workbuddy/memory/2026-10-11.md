# 2026-10-11

## FSCADisplayLink 改造：Selector → 闭包

F 要求把 `FSCADisplayLink` 做成「Selector 转闭包」，减少 `@objc`。

### 关键结论：CADisplayLink **不能**在 Swift 里子类化挂回调（旧版编译不过）

旧文件（今天 14:01 生成）有 3 处硬错误，用 `swiftc -typecheck`（iPhoneOS.sdk / arm64-apple-ios18.0）逐条证实：

| 旧写法 | 编译结果 |
|---|---|
| `import Foundation` | `CADisplayLink` 根本不可见（在 QuartzCore，需 `import UIKit`） |
| `override init(target:action:)` | `initializer does not override a designated initializer from its superclass` —— 标签是 `selector:` 不是 `action:`，且参数是**非可选** `Any`/`Selector`（头文件在 `NS_HEADER_AUDIT` 区，未标注即 nonnull） |
| `addTarget(self, action:)` | `cannot find 'addTarget' in scope` —— CADisplayLink 没有 addTarget（`CADisplayLink.h` 只有 `displayLinkWithTarget:selector:` / `addToRunLoop:forMode:` / `removeFromRunLoop:forMode:` / `invalidate`，`target`/`selector` 均 readonly） |

致命的第三点：`init(target:selector:)` 在 Swift 里是**convenience** 初始化器（`+displayLinkWithTarget:selector:` 导入），子类 designated init 里 `super.init(target:selector:)` 报 `must call a designated initializer of the superclass 'CADisplayLink'`。
⇒ target/selector 只读 + 无 addTarget + 唯一配置入口是 convenience init = **子类无法给自己挂回调，继承方案死路**。

### 改法（已落地）

`FSKit/Classes/FSCADisplayLink.swift` 重写为**组合包装**（不再是 CADisplayLink 子类）：

- `public var onTick: ((FSCADisplayLink) -> Void)?`（原 `onSEL` 改名，无调用方）
- `public init(handler: Handler? = nil)`，尾随闭包可写 `FSCADisplayLink { [weak self] link in ... }`
- `public let link: CADisplayLink` 作逃生口；转发 `isPaused` / `preferredFrameRateRange` / `timestamp` / `duration` / `targetTimestamp` / `add(to:forMode:)` / `invalidate()`
- `deinit { link.invalidate() }`：避免 RunLoop 持有下每帧空转
- 私有代理 `private final class _FSDisplayLinkProxy: NSObject`（沿用 `_FS` 前缀惯例）挂 `@objc func tick(_:)`，**全库唯一一处 @objc**；代理只 `weak var owner` 回指，断开 CADisplayLink 强持有 target 造成的环（头文件：invalidate "releases the 'target' object"）

### 验证

`swiftc -typecheck` 类文件 + 业务侧用法探针（尾随闭包 / 具名 / onTick 赋值 / 转发属性 / `link.remove(from:forMode:)`）全部 EXIT=0。

### 顺带核查

`FSTapGestureRecognizer.swift`（同款写法）typecheck 通过、**不用改**：`UIGestureRecognizer` 有 `addTarget`，且 `init(target:action:)` 是 NS_DESIGNATED_INITIALIZER，子类 override 合法；手势识别器也不强持有 target。
